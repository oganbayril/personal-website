Germany real estate price predictor

Estimates apartment prices in five German cities from 3,000+ scraped listings. Half of estimates land within ±16% of the asking price, and the live demo says plainly what the model can't see.

Live demo Code on GitHub

The question

What is an apartment for sale in Berlin, Hamburg, Köln, Leipzig or München likely to cost, based on what its listing shows? The project answers that end to end: from collecting listings to a price-estimation service anyone can try in the browser.

The result

Built on 3,000+ scraped listings; on a held-out test set, half of estimates land within ±16% of the asking price (about 20% mean error).

A robots-aware, rate-limited scraper feeds PostgreSQL, a shared feature pipeline trains an XGBoost regressor, and a FastAPI service serves predictions behind a web demo. Weekly guarded retraining, nightly backups and CI (ruff, pytest, pip-audit, 80+ tests) keep it running.

Limits: a plain-language model card on the demo states these limits and what the model cannot see (condition, year built, balcony, photos).

Tools

  • Python: robots-aware, rate-limited scraper and a shared feature pipeline
  • PostgreSQL: storage for the scraped listings
  • scikit-learn and XGBoost: the price model (XGBoost regressor)
  • FastAPI: serves predictions behind the web demo
  • Data: apartment listings scraped from immowelt.de
  • Hosting: my own VPS with automatic HTTPS; CI with ruff, pytest and pip-audit
